# Локальные шрифты

Manrope, Playfair Display и DM Mono соответствуют типографике прототипа. Файлы WOFF2 и CSS с диапазонами символов получены из Google Fonts; загрузка страницы не обращается к внешнему сервису.

- CSS-источник: https://fonts.googleapis.com/css2?family=DM+Mono:wght@400;500&family=Manrope:wght@400;500;600;700&family=Playfair+Display:ital,wght@0,400;0,500;0,600;1,400;1,500&display=swap
- Лицензия Manrope: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- Лицензия Playfair Display: https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt
- Лицензия DM Mono: https://github.com/google/fonts/blob/main/ofl/dmmono/OFL.txt

Копии лицензий SIL Open Font License включены рядом с файлами. Соответствие семейств и файлов указано в `fonts.css`.
