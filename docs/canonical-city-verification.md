# Канонический город на этапе извлечения параметров Gemini

Исторический отчёт предыдущего этапа. Теперь `city` заменён общей моделью `region/settlement/district`; актуальное поведение и проверки описаны в [location-verification.md](location-verification.md).

Проверено 10 октября 2026 года. Это уточнение заменяет первоначальную серверную обработку падежей из пункта №1 аудита.

## Поведение

- Gemini получает явную инструкцию и описание поля structured JSON: `city` — каноническое название в именительном падеже для любого сценария с местоположением. Примеры: «в Москве», «из Москвы», «под Москвой» → «Москва»; «в Казани» → «Казань».
- Для нарушения модель извлекает город места нарушения, отличая его от названия реки и других упоминаний. Если город не определён, возвращается `null`.
- `ChatService` передаёт канонический `city` отдельным аргументом существующему `ViolationService`. Подбор организаций выполняется по этому значению; при `null` повторного определения города по тексту `location` нет.
- В `location` Gemini также использует каноническое название явно указанного города, сохраняя адрес и ориентиры. Переход в форму сохраняет эту строку в прежнем `sessionStorage`. Если определён только город, он используется как местоположение, без очистки других полей.
- В backend удалены перечисления падежных форм Москвы и специальные правила для Москвы-реки. Ручные поля обрабатываются буквально по названиям справочника, без LLM. Для выбора местной организации в ручной форме нужно каноническое название, например «Москва, Арбат».
- Схема БД, страницы, ключ Gemini и модель не менялись. Фактические данные по-прежнему берутся из SQLite.

## Реальные проверки Gemini

Команда: `node scripts/test-canonical-city.mjs`. Настройки Playwright и адрес приложения такие же, как у остальных браузерных скриптов.

| Запрос API | Результат |
| --- | --- |
| Куда сдать батарейки в Москве? | `find_disposal`, `city: Москва` |
| Я из Москвы. Куда сдать батарейки? | `find_disposal`, `city: Москва` |
| Под Москвой хочу сдать батарейки. Где есть пункты? | `find_disposal`, `city: Москва` |
| Куда сдать батарейки в Казани? | `find_disposal`, `city: Казань`, пустая выдача демонстрационных пунктов |
| В реку Москва в Коломне сливают грязную воду. Что делать? | `environmental_violation`, `city: Коломна`, без ошибочного выбора московской организации |

В настоящем Chrome дополнительно отправлены три сообщения о сжигании мусора: «В Москве …», «Я из Москвы …», «Под Москвой …». Во всех случаях Gemini вернул `city: Москва`, чат показал московскую организацию. После перехода в форму местоположение содержало каноническое «Москва», рекомендации снова получены из SQLite с московской организацией. Необработанных ошибок JavaScript нет.
